# v0.5.4 Pause UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `polymath disable` visibly + functionally pause pair-polymath. Today the disable only blocks new LLM cycles from starting; statusline keeps rotating stale cached observations and the prompt-injection hook keeps injecting them into Claude's context. v0.5.4 closes the three read paths (statusline display, prompt injection, cache lifecycle).

**Architecture:** No new flags, no schema bumps, no kill-switches. Surgical: one early-exit in the inject hook, one short-circuit in the statusline cache-read loop, one new branch at the head of the idle-fallback chain, one cache-clear call inside the `disable` subcommand. Refactor `polymath cache clear all`'s body into a `_pp_cache_clear_all` helper so `disable` reuses the canonical truncation path instead of duplicating it.

**Tech Stack:** Bash 3.2-portable shell (no `mapfile`, no `${var,,}`, no `local -n`, no `flock`, no `globstar`); bats for tests; jq for JSON; existing color helpers from `bin/statusline.sh`. No new dependencies.

**Source spec:** `docs/v0.5.4-pause-ux-spec.md` (round 1, locked). 4 changes, 6 ACs, ~7 new tests.

**Estimated scope:** 6 plan-tasks, ~70-100 LOC across 4 files, ~8 new bats tests.

**Implementation order (staged so an in-flight partial implementation never makes the cycle worse than today):**

1. **Task 1** — Refactor `cache clear all` into `_pp_cache_clear_all` helper. No behavior change; sets up Task 5.
2. **Task 2** — `hooks/inject-monitor-insight.sh` early-exit when paused (Change 3). Highest-impact / lowest-risk; stops stale advisories from leaking into Claude's context.
3. **Task 3** — Statusline cache-read short-circuit when paused (Change 2). Without this, Task 4's paused branch cannot fire.
4. **Task 4** — Statusline paused fallback at HEAD of idle chain (Change 1).
5. **Task 5** — `polymath disable` calls `_pp_cache_clear_all` (Change 4).
6. **Task 6** — Byte-identity + final regression verification (AC5).

```bash
# _pp_cache_clear_all <cache_dir>
# Truncates lens + tip + injection-idempotency caches in cache_dir.
# Preserves budget files and re-chmod's them + the directory to mode 600/700.
# Canonical truncation path — called by `cache clear all` subcommand AND by
# `polymath disable` (v0.5.4) so visible pause state is immediate.
_pp_cache_clear_all() {
  local _pp_cache_dir="${1:-}"
  [ -z "$_pp_cache_dir" ] && return 1
  [ -d "$_pp_cache_dir" ] || return 0
  find "$_pp_cache_dir" -maxdepth 1 \
    \( -name 'cc-monitor-*.txt' -o -name 'cc-tips*' \) \
    -type f ! -name 'cc-monitor-budget-*' -exec rm -f {} \; 2>/dev/null
  find "$_pp_cache_dir" -maxdepth 1 \
    \( -name 'cc-monitor-injected-hash-*' -o -name 'cc-monitor-injected-time-*' \) \
    -type f -exec rm -f {} \; 2>/dev/null
  find "$_pp_cache_dir" -maxdepth 1 \
    \( -name 'pp-budget-*' -o -name 'cc-monitor-budget-*' \) \
    -type f -exec chmod 600 {} \; 2>/dev/null
  chmod 700 "$_pp_cache_dir" 2>/dev/null || true
}
```
