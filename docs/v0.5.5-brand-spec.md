## Goal

Codify pair-polymath's emerging visual identity into a coherent brand. Today the statusline has accidental brand vocabulary (🪄, ◌, ▸, ✨, SOFT_* palette) but no single mark. v0.5.5 introduces:

1. **`⚛` (atom) — the polymath sigil.** Many specialists orbiting one work. Color-cycles through the lens palette to signal which lens "spoke."
2. **Constellation (`⠁ ⠂ ⠄ ⡀ ⢀ ⠐ ⠠ ⠈`) — the loading mark.** Braille single-dots cycling at 1s tick. Says "many minds quietly present." Appears wherever there's a wait state.

Both are introduced ADDITIVELY — no existing glyph is removed in v0.5.5. After dogfooding, follow-up release decides whether to swap `🪄` → `⚛` on line 1.

## Reframe / non-goals

- **NOT a multi-line expansion.** Statusline stays 2 lines canonical (1 when paused, optional 3 via `PP_STATUSLINE_LINES=3` opt-in). The brand work happens within existing line geometry.
- **NOT a behavior change.** Zero LLM-cycle semantics modified. Brand is purely visual.
- **NOT a new kill-switch.** Brand identity isn't a feature gate. Default-on; the existing PP_EXTERNAL_LLM gate already turns the whole system off.
- **NOT a redesign of `polymath doctor`'s ✓/⚠/✗ semantics.** Those stay; the brand adds a HEADER sigil above the per-check glyphs.
- **NOT signal-coded brand (e.g., `exceeds_200k_tokens` indicator, `thinking.enabled` glyph).** Deferred to v0.5.6.

## The two marks

### Mark 1: `⚛` (atom) — the polymath sigil

**Glyph:** U+269B ATOM SYMBOL. Broad font support across macOS Menlo, Linux DejaVu, Powerline-patched fonts, iTerm2 / Kitty / WezTerm / Terminal.app. Renders as a single cell width.

**Semantic:** many electrons orbiting a nucleus = many specialist lenses orbiting the work-in-focus. Cleanest semantic match to "polymath" of the candidates considered (`❖`, `⬡`, `❋`, `✶`, `⚛`).

**Animation:** static glyph, **COLOR cycles** through the 7-lens palette per cycle. When an advisor line appears at line 2, the leading `⚛` is rendered in the lens's hue. When `⚛` appears on idle/info contexts (e.g., `polymath status` header), the hue cycles per-tick.

**Voice:** the sigil announces "polymath spoke." It's the project's signature.

### Mark 2: Constellation — the loading mark

**Frames:** `⠁ ⠂ ⠄ ⡀ ⢀ ⠐ ⠠ ⠈` (8 single-dot braille positions, U+2801..U+2848). Cycles 1s per frame.

**Semantic:** many minds quietly attending. The dots represent the 7 lenses + 1 "everything else" position. Single dot = one specialist currently in focus.

**Animation:** time-cycled — frame index = `(epoch_seconds % 8)`. Determinism by clock = no inter-process state to coordinate.

**Voice:** the constellation announces "polymath is working but hasn't surfaced output yet." Loading state, never standalone identity.

Seven hues, one per lens. All already defined in `bin/statusline.sh:~273-312` — codifying not adding.

| UX_DESIGN | `SOFT_PURPLE` | `38;5;139m` | reflective, considered |
| ENGINEERING | `SOFT_AMBER` | `38;5;179m` | warm, durable |

| PERF_FINOPS | `SOFT_GREEN` | `38;5;108m` | grounded, calm |
| PRODUCT_BIZ | `CYAN_SOFT` | `38;5;117m` | forward-looking |
| STRATEGIC_FOUNDER | `SOFT_PURPLE` | `38;5;139m` | reflective (shares UX hue) |

### Touchpoint #12 deep-dive (NEW from docs)

Claude Code supports `subagentStatusLine` in `settings.json`:

```json
{
  "subagentStatusLine": {
    "type": "command",
    "command": "~/.claude/subagent-statusline.sh"
  }
}
```

Each polymath cycle dispatches up to 7 lens analysts + 1 critique + (optionally) retries. Each shows as a row in Claude Code's agent panel. Today they're unbranded — `name · description · token count`.

With v0.5.5: a `hooks/subagent-statusline.sh` reads the tasks JSON, recognises polymath-spawned subagents (by name pattern `analyst-*` or by inheriting `PP_ROOT` env), and rewrites the row with `⚛ ANALYST · ENGINEERING · 2.3K tokens` (color-coded by lens). Other subagents pass through unchanged.

**Implementation cost:** ~40 LOC for `hooks/subagent-statusline.sh` + 1 settings.json merge in install.sh + 2 bats tests.

## Multi-line policy (your question, answered)

**Canonical: 2 lines.** Today's geometry stays.

**Paused: 1 line.** Already shipped in v0.5.4. When `PP_EXTERNAL_LLM=0`, line 2 collapses to the paused message. v0.5.5 enhances the paused line with `⚛` prefix:

```
◌ ⚛ paused — LLM cycle disabled (polymath enable to resume)
```

**Opt-in 3 lines via `PP_STATUSLINE_LINES=3`:**

```
⚛ pair-polymath · v0.5.5 · 22/22 healthy
🪄 (main●) [xhigh] ▰▰▰▰▱ 68% $79.95 cpu 5.11
▸ BIZ: pricing telemetry missing for renewals (2m)
```

The 3rd line is the brand header (rendered FIRST, above the existing two). Useful for users in tall terminals who want persistent brand presence. Default off; ~15 LOC opt-in.

**Why not 4 lines:** statusline should not become a dashboard. Long output truncates on small panes. Claude Code docs explicitly warn: "Keep output short — the status bar has limited width, so long output may get truncated or wrap awkwardly."

## refreshInterval requirement

The constellation frames cycle every 1s. Today polymath statusline updates are EVENT-driven (after each Claude message, after `/compact`, etc.). Between events the constellation would freeze.

**Fix:** set `refreshInterval: 1` in `~/.claude/settings.json` during install/onboard. This re-runs `bin/statusline.sh` every 1s independent of events. Does NOT fire LLM cycles — those are gated by `PP_PARALLEL_INTERVAL_S` (default 300s).

**Cost:** 1 bash invocation/sec on the host. Negligible (<0.1% CPU on a modern Mac). No network. No state change.

**Install impact:** `bin/install.sh` must merge `refreshInterval: 1` into `settings.json` alongside the existing `command` field. ~5 LOC.

## Voice + glyph + color do/don't

**Do:**
- Use `⚛` to signal "polymath spoke" — it's the sigil
- Use `◌` for paused/idle — unchanged
- Use `▸` for tip/teacher rotation lines — secondary marker, distinct from advisor
- Use `✨` for fresh-insight emphasis (<60s observation)
- Cycle the palette by lens identity when surfacing lens output
- Keep DIM_A for "presence without demand"

**Don't:**
- Don't replace `🪄` on line 1 in v0.5.5 (defer to v0.5.6 after dogfood)
- Don't use `⚛` for non-polymath output (e.g., a user's own scripts)
- Don't add motion to glyphs that don't already animate (the dot-glyph stays still; only color or position cycles)
- Don't introduce a 4th line
- Don't add `🧠` or `⛁` or other clever signals — defer to v0.5.6 once the core brand is felt

## Risk + edge cases

- **Font without `⚛` glyph:** rare but possible on minimal terminals. Mitigation: `pp_brand_sigil` helper checks if `LC_ALL=C echo "⚛" | wc -c` returns ≥3 bytes (UTF-8 encoded); falls back to `*` (asterisk) if the font is ASCII-only. Bats fixture pins the fallback.
- **OSC 8 hyperlinks corrupted by tmux/screen:** the Claude Code docs warn about this. Mitigation: `FORCE_HYPERLINK` env check + skip OSC 8 wrapping when terminal capability uncertain.
- **`refreshInterval: 1` on Windows Git Bash:** verify the constellation animation actually cycles (Windows fork overhead may make 1s impractical). If problematic, defaults to `refreshInterval: 2` on Windows.
- **Subagent statusline brand on user's non-polymath subagents:** the `subagentStatusLine` script must check the task's `cwd` or `name` pattern to opt out gracefully. Other subagents pass through with the default Claude Code rendering.
- **`PP_STATUSLINE_LINES=3` on narrow terminals:** the 3rd brand header may push line 2/3 off-screen. Documented as opt-in for wide terminals.

## Open questions

- **Q1:** Should the `⚛` on line 1 be opt-in via `PP_BRAND_LINE1=1` or default-add? **Recommend opt-in for v0.5.5** (additive, conservative); default in v0.5.6 after feedback.
- **Q2:** Hue for `⚛` when no lens has recently spoken (idle context)? **Recommend SOFT_PURPLE** (the "polymath identity color" — first lens, semantically "reflection").
- **Q3:** Should the constellation use 8 frames or compress to 4 (`⠁ ⠂ ⠄ ⡀`)? **Recommend 8** — full rotation is more visibly alive; cost is identical.
- **Q4:** Should `polymath disable` ALSO disable the brand sigil (everything goes plain)? **No** — paused state still says "I'm here, just quiet." The `⚛` on the paused line reinforces "polymath is what's paused" (not the user's whole terminal).
